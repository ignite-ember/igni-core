# ignite-ember

igni's backend and CLI are published as [`igni-core`](https://pypi.org/project/igni-core/).
This package is the old name: it installs `igni-core` at the same version,
with the same extras.

```bash
pip install igni-core            # instead of: pip install ignite-ember
```

Source: [ignite-ember/igni-core](https://github.com/ignite-ember/igni-core).
